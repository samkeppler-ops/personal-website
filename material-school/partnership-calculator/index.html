School Partnership Calculator

How many partnerships can your school operate each year? 🌱

Schools bring in nonprofit partners to fill gaps that the budget doesn't cover. The average number you operate at one time comes down to two things: how many new ones you start each year, and how long each one runs before you have to renew or replace it.

First: what's a cycle? ⏳

A partnership's cycle is how many years it runs before you have to do the big setup work all over again.

🔁

A one-year cycle

You've worked with the same after-school program for six years. But every August you write the same application, recruit the same volunteers, and redo the schedule. Six years long, one-year cycle.

📄

A three-year cycle

You wrote one grant, won it, and the funding runs three years. During those years, you just need to keep it oiled and fine-tuned. That's a three-year cycle.

A partnership cycle is not the same as how long you've had the same partner. You might have had a partner for five years, but if you have to renew it every year, it has a one year cycle time.

For districts: the equity view

Put several of your schools side by side. When some start more partnerships than others and everybody gets the same cycle length, the gap between them gets wider, not narrower. This tool shows you by how much, and what would close it.
